# Delivery Roadmap

## Phase 1 — Published source MVP
Single-page vanilla ES-module app, static hosting, synthetic data, filters, CSV, local-only intake, prioritization and Academy Studio. Validate deployment manually in GitHub Pages settings.

## Phase 2 — Governed portfolio application
Authenticated users, database, standardized state machines, approval matrices, controlled financial planning, tamper-evident audit events, capability/value-stream registry, digital adoption and benefits measurement.

## Phase 3 — GitHub and Notion interoperability
GitHub Issues/Projects for work tracking. Notion pages for KM. Use secure, server-side tokens and explicit mappings. Conflict handling: compare source versions; hold concurrent edits for review. No unattended bidirectional synchronization is present today.

## Phase 4 — Intelligence and simulation
AI-assisted problem decomposition, duplicate detection, capability impact analysis and experiment generation. Human reviews remain mandatory for material decisions. Add 11 GICS sector challenges, 12 architecture lenses and 20 lab pathways.

## Exit criteria for enterprise use
Threat model, identity and authorization tests, accessibility validation, disaster recovery, audit export, cost attribution, benefits evidence reconciliation and security sign-off.
